📱 Marker-Based AR App

Works on ALL devices - iPhone, Android, Desktop!

🚀 Quick Start:

  1. Print or display markers (links below)
  2. Allow camera access when prompted
  3. Point camera at marker
  4. Switch models using buttons
  5. See 3D models appear on markers!
